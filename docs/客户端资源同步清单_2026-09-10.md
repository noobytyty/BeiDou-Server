# 客户端资源同步执行清单（2026-09-10）

> 本清单对应 BeiDou-Server 今日技能平衡、现金装备栏位和 Boss Rush 奖励更新。
> 必须在实际运行的 BeiDou-Client 仓库中执行，不能用服务端仓库内的 WZ 文件代替客户端 IMG。

## 1. 本次同步范围

| 类型 | 是否需要客户端同步 | 说明 |
| --- | --- | --- |
| 战士技能数值与说明 | 是 | `Skill.wz`、`String.wz/Skill.img` |

## 2. 执行前输入与备份

```text
SERVER_ROOT = BeiDou-Server 仓库根目录
CLIENT_ROOT = 实际使用的 BeiDou-Client 仓库根目录
PATCHER     = xml-img-patcher.exe 实际路径
OUTPUT_ROOT = 客户端备份和临时输出目录
```

执行前必须：

1. 确认客户端版本与服务端 WZ 版本一致。
2. 完整备份客户端 `Data/` 和 `EN/`。
3. 在 `OUTPUT_ROOT` 生成临时结果，确认无误后再替换正式目录。
4. 记录服务端本次提交 hash，并把该 hash 作为 `export --from` 的输入。

## 8. 推荐执行命令

在实际客户端仓库执行，先 dry-run：

```bash
xml-img-patcher.exe export --from=<本次服务端提交> --repo=<SERVER_ROOT>

xml-img-patcher.exe batch \
  --full-xml-dir=<导出的XML目录> \
  --client=<CLIENT_ROOT> \
  --dry-run

xml-img-patcher.exe batch \
  --full-xml-dir=<导出的XML目录> \
  --client=<CLIENT_ROOT>

xml-img-patcher.exe verify --client=<CLIENT_ROOT>
```

如果只同步指定资源，也可以先将对应服务端 XML dump 为目标 IMG，再执行节点级 `sync`。不要直接使用文本 diff 覆盖二进制 IMG。

## 9. 同步后验收

### 技能

- 战士终极攻击满级显示 `70% / 300%`。
- 斗气集中、愤怒之火、快速武器满级显示 `900秒`。
- 祝福满级显示物防/魔防 `+50`、移速 `+20`、跳跃 `+10`、`900秒`。
- 神圣祈祷满级显示经验 `+50%`、`900秒`。
- 技能实际持续时间与说明一致。

### 现金装备

- 透明披风可放入现金披风栏。
- 透明手套可放入现金手套栏。
- `1702781`、`1702782` 可作为武器皮肤装备到武器栏。
- 披风、手套、武器不会被客户端当成帽子或套服。
- 苹果耳机 `1005948` 仍可按耳饰栏装备。

### Boss Rush

- 每个阶段的新增装备能正常显示名称和图标。
- 领取装备后能正常穿戴。
- 装备词条由服务端生成，客户端不需要动态显示装备实例名称。

## 10. 回滚

出现问题时：

1. 关闭客户端；
2. 恢复备份的 `Data/` 和 `EN/`；
3. 不要回滚服务端数据库迁移，除非明确确认需要数据库回滚；
4. 记录具体 ItemId、技能 ID、客户端语言层和 IMG 路径后再单独修复。
