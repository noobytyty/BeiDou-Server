## 跨机器快速同步流程

1. 在 BeiDou-Client 仓库确认当前分支和客户端版本，先备份 `Data/`、`EN/`。
2. 将本清单列出的服务端 XML 与客户端目标 `.img` 建立对应关系；中文使用 `Data/`，英文使用 `EN/`。
3. 优先使用仓库提供的 `xml-img-patcher`：
   ```bash
   xml-img-patcher.exe export --from=<服务端提交> --repo=<BeiDou-Server路径>
   xml-img-patcher.exe batch --full-xml-dir=<导出的XML目录> --client=<BeiDou-Client路径> --dry-run
   xml-img-patcher.exe batch --full-xml-dir=<导出的XML目录> --client=<BeiDou-Client路径>
   xml-img-patcher.exe verify --client=<BeiDou-Client路径>
   ```
4. `batch --dry-run` 中如果显示 ADD，先确认目标 `.img` 是否已经存在同名子树；已存在时不要重复追加。
5. 同步后检查中文 `Data/Skill`、`Data/String/Skill.img`，英文 `EN/Skill`、`EN/String/Skill.img`。
6. 重点实测技能等级上限、技能说明、动画延迟和实际伤害；快速暗器/快速短刀应只保留 1–10 级。

## 同步后检查

1. 使用 XML 工具或客户端资源工具将服务端 XML 变更应用到客户端 `.img`。
2. 中文客户端检查 `Data/Skill` 和 `Data/String/Skill.img`。
3. 英文客户端检查 `EN/Skill` 和 `EN/String/Skill.img`。
4. 在客户端确认快速箭/快速弩只显示 1–10 级。
5. 在客户端确认快速箭/快速弩 10 级持续时间为 200 秒，而不是无形箭的 900 秒。
6. 创建弓手和弩弓手角色，实测强力击退概率、爆炸箭伤害、穿透箭伤害和无形箭持续时间。
7. 确认客户端技能窗口、技能说明和实际战斗效果一致。
